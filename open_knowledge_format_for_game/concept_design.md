# 🧙‍♂️ 글자 마법사: 기획 의도 및 구현 명세

## 1. 기획 의도 (Project Intent)
- **국어 문해력 및 어휘력 보강**: 스마트폰 사용 증가와 문해력 저하가 우려되는 아동/청소년들을 위해 자주 오용되거나 핵심적인 한글 어휘 100가지를 자연스럽게 체득하게 만듭니다.
- **활동 기반 타이핑 액션**: 방향키나 마우스 조작을 배제하고 오직 화면에 등장하는 핵심 어휘를 직접 타이핑하여 모든 상호작용(공격, 방어, 대피, 아이템 획득)이 수행되도록 설계되어 자판 연습과 연계한 뛰어난 몰입감을 유도합니다.

## 2. 핵심 게임 메카닉 (Gameplay Mechanics)
- **5단계 웨이브 시스템**:
  - **전투 웨이브 (Wave 1, 3)**: 낙하하는 저주 투사체를 요격하며 생존하는 디펜스 단계.
  - **정비 및 회복 웨이브 (Wave 2, 4)**: 저주가 멈추고 학습용 유용한 보급 아이템들이 집중 낙하하여 체력과 은엄폐를 재정비하는 단계.
  - **보스 결전 웨이브 (Wave 5)**: 보스가 잠에서 깨어나 장막을 두르고 하강을 시작합니다. 방패 파괴(파란 마법사)와 본체 타격(붉은 마법사)의 속성 분담 협동으로 보스를 격퇴하는 최종 단계.
- **은엄폐 기믹 및 설치 (Tactical Cover)**:
  - 전장에 무작위 생성되거나 아이템으로 설치한 투명 보호막 장벽 단어를 입력 시 해당 장벽 뒤로 미끄러지듯 스무스하게 대피하여 투사체를 회피합니다.
- **보급 아이템 체계**:
  - 🧪 체력 회복(`heal`), 🪙 점수 추가(`gold`), 🛡️ 보호막 수리(`ward`), 🧱 장벽 신규 설치(`cover`), 🔮 개인 보호막 생성(`shield`) 아이템을 지원합니다.
- **AI 동료 모드 (Solo Mode)**:
  - P2P 연결 없이 바로 구동되는 1인 모드로, 플레이어는 파란 마법사 역할을 하고 👸 AI 마법사 아바타가 보스 본체 타격 및 자가 요격을 80% 확률로 동반 지원합니다.

## 3. 프론트엔드 및 시스템 구현 특성 (Technical Specs)
- **프리미엄 라이트 테마 (Light Mode)**:
  - 깔끔한 `#F1F5F9` 배경과 글래스모피즘 계열 화이트 카드 인터페이스를 채택하여 실시간 시인성을 대폭 강화했습니다.
- **고정 해상도 및 모바일 반응형**:
  - 캔버스의 내부 가상 논리 해상도를 `600x450`으로 강제 고정하고 CSS `object-fit: contain` 처리를 가해 모바일 가상 키보드 팝업 시 화면 찌그러짐과 좌표 계산 왜곡을 차단했습니다.
- **단어 겹침 방지 (Anti-Overlap Physics)**:
  - `Pretext` 라이브러리의 텍스트 폭 계산 API(`Pretext.getTextWidth`)를 매 프레임 구동하여 투사체들이 너무 가까워지면 물리적으로 부드럽게 좌우로 흩어지도록 구현했습니다.
- **가독성 극대화 (Log-only Translations)**:
  - 캔버스 안의 지저분한 번역 괄호 표기를 지우고, 대신 단어 출현 시 실시간 시스템 로그창에 `[사흘] 뜻: 3일` 형태로 번역본을 넘겨주어 화면 간결성을 확보했습니다.
