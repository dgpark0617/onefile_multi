📝 [기획서] 프로젝트 명: 미니 사커 택틱스 (Mini Soccer Tactics)
1. 개요
장르: 20인 동시 턴제(WEGO) 스포츠 전술 게임

플랫폼: Web 브라우저 (PC / Mobile 하이브리드 지원)

핵심 메커니즘: 10초 계획(Planning) 후 동시 실행(Resolution). 공의 타격 부위 및 강도 조합을 통한 물리 기반의 궤적 제어.

네트워크 구조: PeerJS 기반의 Star(방장-참가자) 구조 (멀티플레이 시)  
HTML

2. 게임 모드 구조
항상 20명을 모을 수 없는 환경을 고려하여, 동일한 물리 엔진과 조작계를 공유하는 두 가지 모드를 지원합니다.

① 멀티플레이 모드 (10 vs 10)
20명의 실제 유저가 각자 지정된 선수 1명만 조작합니다.

방장(호스트) 컴퓨터가 20명의 데이터를 취합해 물리 연산을 처리합니다.  
HTML

소통과 팀워크, 수읽기가 핵심입니다.

② 솔로 모드 (싱글 플레이)
유저 혼자서 우리 팀 선수 10명 전체를 조작하거나, 지정된 '에이스 선수 1명'만 조작하고 나머지는 팀원 AI에게 맡깁니다.

상대 팀 10명은 모두 컴퓨터 AI가 담당합니다.

방장 연산 과정을 유저 브라우저가 로컬로 처리하므로 네트워크 대기 시간(10초) 없이, 내가 [명령 입력 완료]를 누르는 즉시 정산되어 속도감 있게 진행됩니다.

3. 핵심 시스템 디자인
A. 조작 및 UI 시스템
선수 이동 (경로 지정): 선수를 선택하고 원하는 위치를 클릭하여 이번 턴(10초 동안) 이동할 최종 목적지(Way Point)를 지정합니다.

킥 인터페이스 (Kick UI, 미니사커스타 방식): 공 점유자가 [킥] 버튼을 누르면 타임스톱 상태로 킥 모드에 진입합니다.

1) 필드 조준: 공 위치에서 드래그하여 화살표 방향(패스/슛 방향)과 화살표 길이(강도)를 동시에 지정합니다.

2) 공 줌인: 조준 확인 후 카메라가 공 클로즈업으로 전환됩니다.

3) 공 표면 터치: 줌된 공의 어느 지점을 누르느냐에 따라 땅볼(중앙), 커브(좌/우), 칩·로브(아래)가 결정되며 탭과 동시에 킥이 예약됩니다. 별도 슛/패스/띄우기 버튼은 없습니다.

B. 턴 진행 프로세스 (WEGO)
계획 단계 (10초): 유저(들)가 이동 및 킥 명령을 예약합니다. (솔로 모드에서는 시간 제한을 해제하여 신중한 전술 구상이 가능하도록 옵션 제공 가능).

정산 단계 (0.1초): 모든 명령 값(이동 좌표, 킥 타격점, 강도 등)을 물리 엔진 수식에 대입하여 10초간의 공과 선수 움직임을 시뮬레이션합니다.  
HTML

연출 단계 (3초): 시뮬레이션된 대본을 바탕으로 60FPS의 부드러운 실시간 애니메이션을 재생합니다.  
HTML

4. 솔로 모드를 위한 AI 시스템 구성
혼자서도 멀티플레이의 긴장감을 느끼게 하기 위해, AI는 유저와 동일한 규칙(10초 단위 예측)으로 움직입니다.

A. 팀원 AI (내가 1명만 조작하는 솔로 모드일 때)
지지(Support) AI: 유저가 공을 잡으면 주변 팀원 AI들은 스루패스를 받기 위해 상대 수비수 사이의 '빈 공간(Open Space)'을 찾아 자동으로 이동 경로를 예약합니다.

공간 확보: 유저가 전진하면 수비수 유인 조작을 자동으로 수행합니다.

B. 상대 팀 AI (컴퓨터)
예측 수비 AI: 유저 선수의 킥 UI 조준 방향과 공 타격 각도를 실시간으로 읽고, 공이 휘어 들어올 궤적(낙하지점)이나 패스 길목을 예측하여 차단 경로를 예약합니다.

난이도 조절: AI 등급(하급/중급/월드클래스)에 따라 유저의 킥 모션을 보고 반응하는 속도와 예측 정확도(확률)에 차등을 둡니다.

6. 개발 로드맵 제안
1단계 (로컬 물리 검증): 솔로 모드를 기준으로 브라우저 안에서 공의 타격 부위/강도에 따라 바나나킥, 칩슛이 구현되는 2D 물리 엔진을 먼저 개발합니다.

2단계 (싱글 전술 AI 구현): 컴퓨터 아군과 적군 AI를 붙여 혼자서 전술 축구를 주고받는 '솔로 모드' 프로토타입을 완성합니다.

3단계 (PeerJS 멀티플레이 확장): 검증된 물리 엔진 데이터를 PeerJS의 Star 구조로 연결하여, 로컬 연산 결과를 다른 유저들에게 브로드캐스트하는 멀티플레이 기능을 얹습니다.
