# Neon Rush — 실시간 P2P 레이싱 (중단 / FAIL)

> **파일:** `onefile_multi_racing_fail.html`  
> **상태:** FAIL — 더 이상 진행하지 않음. 솔로 pseudo-3D만 그나마 동작, 멀티는 프로토타입 수준.

- 1인칭 OutRun식 pseudo-3D · 네온

| | |
|--|--|
| 솔로 | 도로·벽·속도감 — 대체로 OK |
