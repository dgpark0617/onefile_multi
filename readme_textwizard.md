# 🧙‍♂️ 글자 마법사: 속성 분담형 P2P 레이드 (종합 문해력 학습 버전)

서로 다른 속성을 분담하여 '단어 괴물'을 퇴치하고, 실시간으로 떨어지는 저주 단어를 요격하는 **2인 협동 타이핑 레이드 게임**입니다. 최근 학생들의 국어/영어 문해력 향상 및 어휘력 강화를 목표로 합니다.

## 게임 기믹 및 조작 (Typing Only)
모든 이동, 아이템 습득, 공격 및 요격은 방향키나 마우스 없이 **오직 영어 단어 혹은 고급 한국어 어휘 타이핑**을 통해서만 이루어집니다.

1. **지형 엄폐 이동**:
   - 맵에 배치된 장애물(기둥) 상단에는 `금일` / `(오늘)` 또는 `mitigate` / `(피해를 완화하다)`처럼 **학습용 어휘와 뜻**이 함께 표시됩니다.
   - 해당 어휘의 철자(`금일` 또는 `mitigate`)를 입력하면, 마법사가 해당 기둥 뒤의 X 좌표로 즉시 순간 이동(엄폐)합니다.
   - 보스의 저주 투사체가 다가올 때 기둥 뒤로 대피하면 체력을 지킬 수 있습니다.
2. **아이템 획득**:
   - 하늘에서 떨어지는 아이템(🧪 체력 물약, 🪙 금화, 🛡️ 장벽 강화) 위에 학습 단어와 뜻이 표시됩니다.
   - 단어를 정확히 타이핑하면 아이템을 습득해 효과를 적용받습니다.
3. **보스 및 저주 요격**:
   - 나에게 떨어지는 저주 영어/국어 단어를 타이핑하면 공중 요격이 가능합니다.
   - 보스의 방패(파랑) 또는 본체(빨강)에 표시된 어휘 단어(예: `사흘 (3일)`)를 타이핑하면 마법 미사일이 날아갑니다.

## 기술적 특징
- **PeerJS (WebRTC)**: 방장과 참가자의 화면, 맵 지형 파괴 상황, 동적 위치를 실시간 동기화.
- **Pretext.js**: Canvas 상에서 단어의 가변 히트박스 영역을 백그라운드에서 선계산하여 프레임 최적화.
- **HTML5 Canvas 물리 입자**: 단어 파괴 시 자모음 텍스트 파편들이 중력, 회전 물리량에 의해 터지는 연출.
